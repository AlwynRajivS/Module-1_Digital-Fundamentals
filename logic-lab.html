Concept

Why NAND and NOR matter

Every Boolean function — AND, OR, NOT, XOR, anything — can be built from NAND alone, or from NOR alone. That's why they're called universal gates: fabricate one gate type and you can wire up any digital circuit from it. Flip the switches below each symbol to see the gate respond live.

IEEE Symbols

The gate gallery

Distinctive-shape (IEEE Std 91) symbols: AND is a flat-back D, OR is a curved shield, NOT is a triangle. NAND / NOR are the same bodies with a small bubble added at the output — the bubble means "invert".

Universal Gates

Building blocks from NAND alone

Tie both NAND inputs together to invert a signal. Chain two NANDs to recover AND. Invert each input first to get OR. Toggle A / B to watch the signal ripple through each build.

Building blocks from NOR alone

The same trick works in reverse with NOR: tie inputs together for NOT, invert-then-NOR for AND, and a bare NOR already gives you the inverse of OR.

Exclusive Gates

XOR and XNOR from NAND alone

XOR needs 4 NANDs. Tap one more NAND onto the output and it inverts into XNOR. Toggle A / B and watch all four gates light together.

XOR and XNOR from NOR alone

The same 4-gate skeleton built from NOR gives you XNOR directly; add a fifth NOR as an inverter to flip it into XOR.

Boolean Function

Implementing F = AB + C′

Real designs start from a Boolean expression, not a gate list. Here's the same function — F = AB + C′ — built two ways: a lean 2-gate NAND circuit using bubble-pushing, and a longer NOR-only version built strictly from NOR-based AND/NOT blocks. Toggle A, B, C to compare.

Quick reference — NAND = NOT(A AND B). Output is 0 only when every input is 1.
NOR = NOT(A OR B). Output is 1 only when every input is 0.

Sandbox

Build a circuit

  1. Add gates — tap a block in the toolbar to drop it on the board.
  2. Wire it up — drag from a gate's output pin (right, filled dot) to another gate's input pin (left, hollow dot). Drag from an already-wired input pin to detach it.
  3. Drive it — tap an INPUT block to flip it between 0 and 1. Wires glow amber the instant they carry a 1.
  4. Rearrange — drag a gate's body to move it; tap it to select, then use Delete. Clear wipes the board.
  5. Pick a problem below to get a labeled A/B/C → OUTPUT scaffold, build your circuit, then hit Check Circuit.
